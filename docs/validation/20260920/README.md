## 独立行为测试

每个受测会话只获得任务请求、原始材料与 Skill，未获得维护者标准或其他会话结论。材料均为程序生成示意数据；维护者核对实际产物和输入哈希，并充当模拟用户回答追问。具体模型版本和推理参数未单独留存，这次记录不用于不同模型之间的比较。

| 场景 | 实际观察 |
|---|---|
| 已有标签 | 检查12张已有标签和现有工程，准备后续方案；没有重复预标注 |
| 扩数后仍漏检 | 发现新增60个目标均为大框，小目标没有增加；又查出16张验证图主体与训练图重复 |
| 新旧指标变化 | 复算两模型、两套标签的4组结果，识别口径差异并保留逐图退步样例 |
| 接续与规则变化 | 核对原模拟作业已完成；修订明确的布帽标签，含糊样本询问后留出 |
| 旧工具报错 | 读取帮助和源码，修复参数与类别映射，验证3图3框输出 |
| 少量标签起步 | 检查8图、整理候选并补漏标，输出7份标签7框；用品规格含糊的一图询问后留出 |

其中“主体重复”是受测会话主动发现、原始维护者预期未覆盖的问题。主评审又独立计算了像素主体哈希，确认16张验证图的结果；来源组名字不同并未证明图像内容独立。

“新旧指标变化”另做了一次无 Skill 的同材料对照。两边都能完成关键诊断与交叉重算，因此这一单例没有证明 Skill 的净提升，更不能推算普遍成功率或节省比例。后续会结合普通开发者试用检查关键遗漏、交互负担和任务接续情况。

6个有Skill场景均完成各自范围内的工作。标注对照页因本地URL策略未能在浏览器渲染，已检查页面结构和内嵌资源；不将其写为界面验收。

各次结论、输入身份与已审阅输出摘要见 [行为记录](behavior.json)。完整会话和工作文件保留在本次私有运行目录；[公开生成器](../../../evals/README.md)可重新生成材料，但AI会话的具体行为需要再次运行观察。

## 真实训练与导出

复用公开 Hardhat 来源，检查已有标签后训练383张、6轮。第2轮保存检查点后终止子进程，成功从第3轮恢复。检查中发现疑似漏标、近重复和评价配置问题，保留原结果并完成相应修订与重算。

16张真实图的ONNX核对保留了初次统一容差失败，再按坐标与概率的单位分别复核。另一次实际SSH退出后，后台4图复核继续完成，重连读取同一作业，未重复启动。

详情见 [真实执行报告](real-training.md)、[训练与导出数值](real-training.json)、[SSH断开记录](ssh-disconnect.json)。这些结果来自同来源材料，重点验证执行和判断能力，尚有桌上安全帽误检、低头及重叠人头漏检。

Mac上独立x86 Docker实例完成模型导入、4图25框对照、视频编排和1条未戴帽事件。取回图片与录像，录像完整解码；任务停止状态已读回。

实时抓流超时与录像时间戳警告保留在 [应用报告](cosmoedge.md) 中，未把接口成功当作所有媒体行为都通过。没有据此宣称其他芯片、完整视频召回率或现场验收。
